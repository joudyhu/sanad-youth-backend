# مراجعة مشروع سند الشباب (Sanad Youth Backend)

## 1. نظرة عامة على المشروع

سند الشباب هو تطبيق للواجهة الخلفية (Backend)، تم تطويره باستخدام NestJS وTypeScript وPrisma ORM وPostgreSQL.

## 2. التقنيات المستخدمة

* **NestJS:** إطار عمل لتطوير الواجهة الخلفية.
* **TypeScript:** لغة البرمجة الأساسية المستخدمة في المشروع.
* **PostgreSQL:** نظام إدارة قواعد البيانات العلائقية.
* **Prisma ORM:** أداة للتعامل مع قاعدة البيانات وإدارة البيانات.
* **JWT:** تقنية المصادقة باستخدام الرموز (Tokens).
* **Bcrypt:** تقنية لتشفير كلمات المرور وتخزينها بشكل آمن (Hashing).
* **Helmet:** إضافة لتعزيز أمان تطبيق الويب.
* **ValidationPipe:** للتحقق من صحة البيانات المرسلة إلى الخادم.
* **Class-based Validation:** للتحقق من صحة البيانات الواردة.
* **Throttler:** لتحديد عدد الطلبات المسموح بها خلال فترة زمنية.
* **Cache Manager:** لدعم التخزين المؤقت للبيانات.

## 3. الوحدات المنفذة في المشروع

* **المصادقة (Authentication):** تسجيل المستخدمين وتسجيل الدخول.
* **المستخدمون والصلاحيات (Users and Roles):** إدارة صلاحيات المستخدمين حسب أدوارهم: شاب، مشرف، ومدير.
* **البرامج (Programs):** إنشاء البرامج وعرضها وإدارتها.
* **جلسات البرامج (Program Sessions):** إدارة الجلسات المرتبطة بالبرامج.
* **طلبات التقديم (Applications):** إرسال الطلبات وعرضها وإلغاؤها ومراجعتها.
* **الإعلانات (Announcements):** إنشاء الإعلانات وعرضها.
* **رفع الملفات (File Uploads):** رفع السير الذاتية (CVs) وصور البرامج والمواد التعليمية.
* **المواد (Materials):** الوصول إلى المواد المرفوعة الخاصة بالبرامج.
* **العمليات الإدارية (Admin Operations):** إنشاء حسابات المشرفين.

## 4. قاعدة البيانات

يستخدم المشروع PostgreSQL مع Prisma ORM.

الجداول الرئيسية في قاعدة البيانات:

* User: المستخدمون.
* Program: البرامج.
* Session: جلسات البرامج.
* Application: طلبات التقديم.
* Announcement: الإعلانات.
* Material: المواد المرفوعة.

## 5. ميزات الأمان

* المصادقة باستخدام JWT.
* تشفير كلمات المرور باستخدام Bcrypt (Hashing).
* التحكم بالصلاحيات حسب دور المستخدم.
* التحقق من صحة البيانات باستخدام ValidationPipe.
* تعزيز أمان HTTP باستخدام Helmet.
* تحديد عدد الطلبات باستخدام Throttler.

## 6. ميزات إضافية

* إدارة السعة الاستيعابية للبرامج.
* استخدام معاملات قاعدة البيانات (Database Transactions) أثناء عمليات التقديم.
* تخزين الملفات على الخادم المحلي.
* إعدادات CORS للتحكم بالاتصال من مصادر مختلفة.
* دعم التخزين المؤقت (Caching).

## 7. حالة الاختبار والمراجعة

تمت مراجعة الكود المصدري للمشروع بشكل ثابت.

كما تم إجراء فحوصات أساسية للبناء وبعض واجهات API سابقاً، لكن لم يتم التحقق من وجود مجموعة اختبارات آلية شاملة أو التأكد الكامل من جاهزية المشروع لبيئة الإنتاج.

## 8. التحسينات المستقبلية

* إضافة اختبارات آلية شاملة.
* تعزيز التحقق من الملفات المرفوعة وأمانها.
* ضبط CORS للسماح بالمصادر الموثوقة فقط.
* مراجعة إعدادات قاعدة البيانات ومتغيرات البيئة.
* تجهيز التطبيق للنشر في بيئة الإنتاج.
